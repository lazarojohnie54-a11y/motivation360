# Motivation 360

Tovuti ya motisha na maarifa kwa jamii, iliyoanzishwa na **GENIUX** — wakala wa kwanza wa AI Afrika Mashariki.

## Maelezo
- **Jina:** Motivation 360
- **Mtengenezaji:** GENIUX (aliundwa na Lazaro John, miaka 17, Dar es Salaam)
- **Lengo:** Kuimarisha, kuelimisha, na kufundisha jamii kupitia video za YouTube na PDF za motisha.
- **Fansa:** Afrika Mashariki, na mahususi kwa vijana na biashara ndogo.

## Mafaili Muhimu
- `index.html` – ukurasa wa kwanza ya tovuti (black & white modern design)
- `Nguvu_ya_Kuamini_GENIUX.pdf` – PDF ya kwanza ya motisha (Kiswahili)
- `videos_orodha.txt` – orodha ya vipeo vya YouTube (embed-friendly)

## Kuanzisha Tovuti
1. Clone repo hii:  
   ```bash
   git clone https://github.com/lazarojohnie54-a11y/motivation360.git
   cd motivation360
   ```
2. Hakikisha umewekta mafilio yote hapa (index.html, PDF, etc.)  
3. Pushee mabadiliko:  
   ```bash
   git add .
   git commit -m "GENIUX: Mwanzo wa Motivation 360"
   git push origin main
   ```
4. Nenda pakua GitHub → Settings → Pages → weka **main** branch, folder `/ (root)`, then Save.  
5. Tovuti itakuwa live kwenye:  
   https://lazarojohnie54-a11y.github.io/motivation360/
